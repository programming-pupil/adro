# ADRO About

Use the following values for the repository About panel:

```text
Description: Auditable, recoverable agent workflows for software delivery, testing, repair, and release evidence.
Homepage: https://github.com/programming-pupil/adro
Topics: ai-agents, software-delivery, workflow-orchestration, developer-tools, release-engineering, auditability, golang, open-source
```

ADRO is an independent open-source delivery control plane. It turns a goal,
bug, or analysis task into a policy-bound workflow, preserves the execution
context across repair, and produces evidence that can be reviewed before a
release is accepted. The local profile runs directly on Go without Docker;
production integrations are installed through versioned provider-neutral SPIs.

The GitHub About panel is repository metadata and cannot be changed by a Git
commit. Apply the values above in **Settings → General → About** when publishing
the repository.
